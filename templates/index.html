AUTHENTICATION MECHANISM

All protected endpoints require a valid JSON Web Token passed in the Authorization header using the Bearer schema: 

Authorization: Bearer <ACCESS_TOKEN>

Access tokens expire in 60 minutes. The frontend automatically attempts refresh token exchange upon receiving a 401 Unauthorized status.

REST API ENDPOINTS
POST /api/v1/auth/register/ Register a new user account (returns User object) Public
POST /api/v1/auth/token/ Obtain JWT access & refresh token pair Public
POST /api/v1/auth/token/refresh/ Refresh an expired access token using refresh token Public
GET /api/v1/auth/me/ Retrieve current authenticated user profile Bearer
PATCH /api/v1/auth/me/ Partially update current user credentials Bearer
GET /api/v1/tasks/ List user's tasks with search, filters, sorting & pagination Bearer
POST /api/v1/tasks/ Create a new task with ownership binding Bearer
GET /api/v1/tasks/statistics/ Retrieve aggregated status, priority & overdue counts Bearer
GET /api/v1/tasks/{id}/ Retrieve task details (enforces IsOwner permission) Bearer
PUT /api/v1/tasks/{id}/ Full update of task attributes Bearer
PATCH /api/v1/tasks/{id}/ Partial update of task status, priority, or dates Bearer
DELETE /api/v1/tasks/{id}/ Permanently remove task (returns 204 No Content) Bearer
